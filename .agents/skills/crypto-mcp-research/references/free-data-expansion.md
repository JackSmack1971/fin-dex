## Routing contract for any later adapter

- Route only a specifically requested evidence class to an exact documented endpoint; require chain plus contract for token-level data and pair/pool identity for venue observations.
- Record status independently as `CONFIGURED`, `DISCOVERED`, `RESPONDED`, `QUALIFIED`, or `UNAVAILABLE`. Registration, an HTTP 200, or a valid-looking body does not establish free entitlement or qualification.
- Keep endpoint authorization, request budget, cache duration, and credential state explicit. This repository's workflow permits only anonymous/free read-only calls; never send a key or follow a paid-plan prompt.
- Preserve provider, exact endpoint/tool, upstream source where known, chain/contract/pair, units, event/observation timestamp, retrieval UTC, response coverage, and caveats.
- Treat missing, malformed, stale, throttled, unauthorized, payment-required, and exhausted-fallback results as distinct outcomes. Never convert missing fields to zero or a security pass.
- Mark source independence only when upstream collection is distinct. DEX Screener's own indexer and a separate indexer can provide distinct observations, but wrappers over one data source cannot.
- Cache historical observations as immutable fixtures/manifests when captured. Replay proves calculations over retained data, not the truth of the upstream provider.
