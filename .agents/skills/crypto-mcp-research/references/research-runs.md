# Reproducible research-run format (v1)

Each run is a local directory containing `manifest.json` and retained artifacts. The manifest is described by `assets/research-run.schema.json`; validate it with `python scripts/validate_research_run.py path/to/manifest.json`. The validator is offline. `--replay` explicitly replays calculations from local artifacts and cannot invoke MCP, HTTP, or other providers.

The manifest records task, UTC start/completion, canonical asset identity and resolution status, research horizon, methodology version, configuration references, repository provenance, selected specialists and their execution statuses/handoff paths, evidence-ledger paths, synthesis revision and digest, review bindings, verdict, artifacts and calculations. At most three specialists may be listed. Reviews bind to the frozen synthesis only after collection and reconciliation are complete under the existing handoff lifecycle contract. Partial, blocked, failed, or open runs remain valid records; they do not imply successful research.

Every artifact entry stores a path relative to the manifest directory, a kind and lowercase SHA-256 of the exact retained file bytes. Paths must remain inside the run directory. Digests do not cover the manifest itself or external services. For structured snapshots, use canonical JSON: UTF-8, sorted object keys, compact separators `(',', ':')`, Unicode preserved, and NaN/Infinity rejected; hash those exact bytes. Review snapshot digests bind the complete frozen synthesis JSON value. Artifact digests bind exact stored bytes, including whitespace/newlines. These checks detect changes but do not provide signatures or tamper-proof storage.

Observation fixtures use `{"observations":[{"id":"obs-a","value":10}]}` (a bare array is also accepted). Calculation records name a versioned formula, two input observation IDs, output unit, sampling window, rounding convention, missing-data behavior, expected value and nonnegative tolerance. V1 formulas are `difference.v1` (`right-left`), `ratio.v1` (`right/left`), and `percent_change.v1` (`(right-left)/left*100`). Missing/non-numeric/non-finite inputs and zero denominators fail; there is no implicit fill, current-value lookup, or provider fallback. Replay checks the recorded expected result within its declared tolerance; calculations can be reproduced from retained inputs, while external observations cannot be regenerated or proved true by retaining API responses.

For Git workspaces record the revision string captured for that run. If Git metadata is unavailable, set repository status to `UNAVAILABLE`, revision to null, and give a reason. Do not invent a repository identity. Configuration references are descriptive paths or IDs; their content should also be retained as a hashed artifact if exact configuration reproduction is required.

The manifest itself is the run index and is intentionally not self-hashed. No files are uploaded and no provider is contacted during validation or replay.
